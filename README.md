# KamBau — strona firmowa

Landing firmy budowlanej (Rywałd). Treści na podstawie Facebooka.

## Start lokalnie

```bash
cd C:\Users\Asus\Projects\creator-website
npm install
npm run dev
```

Otwórz [http://localhost:3000](http://localhost:3000).

## Zdjęcia z Facebooka

Zobacz `public/ASSETS.md` — wrzuć pliki pod wskazane nazwy.

## Stack

- Next.js 15 (App Router)
- TypeScript
- CSS własne (bez Tailwind)
- Fonty: Barlow Condensed + Barlow
